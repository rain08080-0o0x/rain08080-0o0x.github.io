自己紹介

仕様通りに実装するだけでなく、処理の責務やデータの流れを整理しながら、 あとから手を入れやすい構成にまとめることを大切にしています。

これまで C++ / DirectX11 でのゲーム制作では、ダイスの物理挙動、OBB 判定、摩擦、重力、回転、停止判定などを扱ってきました。 実装時に問題が起きた場合は、現象だけを追うのではなく、原因を一つずつ切り分けながら確認しています。 例えば「なぜ跳ね続けるのか」「どこで状態が上書きされているのか」「どの処理を分離すべきか」を整理し、 挙動と設計の両方を見直す形で改善してきました。

Unity では UI 設計や Editor 拡張にも取り組み、CardView、UIManager、InputProvider、LayerManager のように 役割ごとに処理を分けながら、入力、表示、選択状態、データ管理を整理する実装を進めています。 ScriptableObject を一覧表示・編集できるツールや、Canvas 上に UI 部品を生成する EditorWindow など、 制作効率を上げる仕組み作りにも関心があります。

実装中の問題を感覚で直すのではなく、構造から原因を確認し、再利用しやすい形へ整えていく姿勢をこれからも磨きながら、 ゲームの面白さを支えるシステムやツールを設計・実装の両面から改善できるプログラマーを目指しています。

得意な技術領域

私の得意な技術領域は、ゲームシステムの実装と、開発効率を高めるツール制作です。

C++／DirectX11では、ダイスの物理挙動、OBBによる当たり判定、摩擦、重力、回転、停止判定など、ゲーム内の挙動を制御する処理を実装してきました。 特に、想定通りに動かない挙動に対して、変数の更新タイミングや状態遷移を確認しながら原因を切り分け、改善することを意識しています。

またUnityでは、UI設計やEditor拡張に取り組んでいます。UIManager、CardView、InputProviderのように、入力、表示、選択状態、データ管理の責務を分ける設計を行いました。 加えて、ScriptableObjectの一覧表示・編集ツールや、Canvas上にUI部品を生成するEditorWindowなど、制作作業を効率化するための仕組み作りにも関心があります。

これらの経験から、私はゲームの動きを支える低レイヤー寄りの実装と、制作現場を支えるツール開発の両方に強みがあります。

チンチロローグライク

制作形態個人制作
ジャンル物理挙動 / ローグライク
作成期間2025/10 〜 2025/12
担当箇所ダイス物理挙動、当たり判定、RigidBody、汎用化
使用ツールVisual Studio 2022 / GitHub / ImGui
言語C++
APIDirectX11

担当箇所で行った内容

ボードゲームで体験したダイスの動きの面白さを、ゲーム上の物理挙動として再現することを目的に制作しました。 ダイスが転がる、跳ねる、回転する、停止するまでの挙動を扱うために、重力、摩擦、回転、停止判定などを一つずつ実装しました。

当たり判定では OBB やコライダーの扱いを検討し、求めている挙動に合わせて RigidBody を作成しました。 単に物体を動かすだけではなく、質量を考慮した挙動になるようにし、ダイスが不自然に跳ね続ける原因や、状態が上書きされる箇所を切り分けながら改善しました。

今後ほかのプロジェクトでも使えるように、物理挙動を行う関数の汎用化やコンポーネント化も意識しました。 処理の責務を分けることで、調整や再利用がしやすい形に近づけています。

課題

  • メッシュコライダー利用のため処理負荷が高い
  • 最適化の継続が必要

探索型サバイバルローグライト（誠意制作中）

制作形態個人制作
ジャンル探索型サバイバル / ローグライト
作成期間2026/05 〜 制作中
担当箇所プレイヤー操作、敵挙動、UI、アイテム、地形生成エディタ
使用ツールVisual Studio 2022 / Visual Studio Code / Fork / GitHub / ImGui
言語C++
APIDirectX11

担当箇所で行った内容

これまでより大きい規模のゲーム制作を想定し、探索、採掘、帰還、売却、再探索という基本ループを検証するために制作しています。 プレイヤー操作では、移動、ダッシュ、回避、採掘、ロープ昇降、所持品確認、全体マップ確認、攻撃などを実装し、探索中に必要な行動を一通り扱えるようにしました。

ステータス面では、体力、スタミナ、精神力の増減を実装しています。 特にスタミナや精神力は、行動やロープ昇降などのゲーム内行動と結びつけ、単なる数値表示ではなく、探索判断に関わる要素として扱えるようにしています。

敵については、一定距離まで近づいたときにプレイヤーへ接近し、さらに距離が詰まると攻撃する挙動を実装しました。 UI ではピン設置やマップ表示を作成し、敵、採掘ポイント、ロープ、プレイヤー位置を確認できるようにしています。 また、採掘で取得するアイテムや敵討伐で入手するアイテムを実装し、探索結果を管理できるようにしました。

制作中に必要になった地形生成エディタも作成しています。 実際のゲーム制作でどのようなツールが必要になるかを確認しながら、ゲーム本体とツールの両方を並行して改善しています。

今後の実装予定（プロトタイプ）

  • プレイヤー: 回避距離調整、スタミナ消費見直し
  • 敵: 巡回 AI、縄張り侵入への反応、報酬アイテム追加
  • UI: ピン種類追加、リセット挙動の設定化
  • アイテム: 売却専用以外のインゲーム利用拡張

開発中に制作した/する予定のツール

  • 地形生成エディタ
  • UI アニメーションエディター
